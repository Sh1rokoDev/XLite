# 界面与下载来源统计更新

日期：2026-11-02。

## 0.1.2 任务卡片与悬浮搜索

- 多选条按钮使用紧凑内边距与自然高度，避免固定高度裁切文字；放大字体时正常撑开。
- 搜索从图标下方悬浮弹出，标题与筛选器不随展开移动。Esc 或点击外部收起并保留搜索条件，关闭按钮清空条件。
- 任务左侧使用大状态图标，右侧依次为文件名、完整链接与大小/百分比、进度条。链接按剩余宽度单行省略，主操作按钮仍互斥显示，进度条仍等长。
- 浅色、深色和 1.4 倍字体渲染检查通过；92 项 JVM 测试通过，新增搜索展开前后标题及筛选器位置不变的检查。

## 0.1.1 任务操作和设置

- Windows 打开文件与文件夹改用系统 ShellExecuteEx，保持 Unicode 路径；需要提权时交由系统提示。打开失败不再一律误报文件移动或删除。
- 文件按钮使用文件/打开图标，与暂停、继续、重试共用固定宽度操作位，按任务状态互斥显示。文件夹按钮始终外置，任务更多菜单移除这两项重复操作。
- 任务筛选在宽窗口位于标题右侧并靠左；多选是与搜索一致的图标按钮，移除顶部更多菜单。
- 多选条包含全选、反选、暂停、继续、删除和取消；与任务列表左右边缘对齐，在宽窗口保持紧凑单行。全选、反选作用于当前筛选结果。
- 账号卡片左侧显示“状态”和连接情况两行，右侧排列连接详情、测试连接、清除密钥与更换 API Key。
- 上传和下载限速均支持 KB/s、MB/s、GB/s，允许小数；单位切换保留原限速，转换到 SDK 整数 KB/s 时向上取整，拒绝无效及越界数值。
- 移除关于卡片的 SDK 隶属关系文案。
- 91 项 JVM 测试通过，覆盖多选范围、外置按钮、单位换算和四种任务状态的进度条等宽；另用无界面测试 EXE 实际验证 Windows 原生打开中文、空格和特殊字符路径，未运行用户下载的安装程序。

## 下载来源

官方接口：https://open.xunlei.com/doc/download/api/xl_dl_get_task_info

`getTaskInfo(taskId, "traffic")` 提供 `origin_size`、`p2p_size`、`p2s_size`，分别是原始 URL、P2P、P2S 累计下载字节数。`dcdn_size` 为保留字段，不展示。

- 任务详情展示三种来源的字节数、占比及分段条。
- 分母为三种来源流量之和，不以文件大小推算来源，不将来源占比解释为提速倍数。
- 无统计或查询失败时显示“暂无来源统计”；总流量为零时显示“等待下载数据”。失败的查询不覆盖已取得的数据。
- 活动任务随状态轮询更新，完成时保存最后一次读取结果；已保存的结果跨重启保留，旧任务可在对账时补取。
- 兼容 Java 返回的 JSON 包装、snake_case / camelCase 字段；拒绝负值、缺失字段与无效 JSON。
